## About IPhySims

The **International Physics Simulation Society** is an open-source, non-profit international organization dedicated to curating, validating, and disseminating high-quality physics simulations for the global scientific and educational community.

We are building the world's most trusted collection of physics simulations — each one peer-reviewed for scientific accuracy, code quality, reproducibility, and educational value.

### Why IPhySims?

- **Authoritative**: Every simulation undergoes rigorous peer review by domain experts
- **Open Source**: All simulations are freely available under open-source licenses
- **Reproducible**: Verified to produce consistent results across platforms
- **Educational**: Curated for use in teaching and learning physics
- **Community-Driven**: Built by physicists, for physicists

## Simulation Domains

IPhySims curates simulations across all branches of physics:

| Domain | Examples |
|--------|----------|
| **Classical Mechanics** | Orbital mechanics, rigid body dynamics, oscillations |
| **Electromagnetism** | Field visualization, wave propagation, antenna patterns |
| **Quantum Mechanics** | Wave functions, potential wells, quantum tunneling |
| **Thermodynamics** | Gas laws, heat transfer, entropy demonstrations |
| **Optics** | Ray tracing, interference, diffraction patterns |
| **Nuclear & Particle** | Decay chains, scattering, detector simulations |
| **Astrophysics** | N-body problems, stellar evolution, cosmological models |
| **Condensed Matter** | Crystal lattices, band structure, phonon dispersion |
| **Fluid Dynamics** | Navier-Stokes solvers, turbulence, flow visualization |
| **Computational Methods** | Monte Carlo, molecular dynamics, finite element methods |

## Organization Structure

### Governance
IPhySims is governed by a **Governing Board** elected by the membership:

| Position | Role |
|----------|------|
| President | Chief executive leadership |
| Vice President | Deputy leadership |
| Secretary | Records and communications |
| Treasurer | Financial management |
| Technical Director | Technical infrastructure and review process |
| Education Director | Educational initiatives and outreach |
| Members-at-Large (×3) | General board members |

### Editorial Board
Domain experts who oversee the peer review process and maintain review standards.

### Membership Categories
- **Founding Members** — Original charter signatories
- **Full Members** — Active contributors and reviewers
- **Associate Members** — Users and occasional contributors
- **Student Members** — Enrolled students (free membership)
- **Honorary Members** — Distinguished individuals

See the [Charter](./CHARTER.md) for complete details.

## Review Process

All simulations undergo a multi-step review process:

```
Submission → Initial Screening → Peer Review (×2) → Author Revision → Editorial Decision → Publication
```

Simulations are evaluated on:
1. **Scientific Accuracy** (40%) — Correctness of physics
2. **Code Quality** (25%) — Clean, documented, tested code
3. **Reproducibility** (20%) — Consistent results across platforms
4. **Educational Value** (15%) — Effective for learning

See [Review Standards](./REVIEW_STANDARDS.md) for full details.
